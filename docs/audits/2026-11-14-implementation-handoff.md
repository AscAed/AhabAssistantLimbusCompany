- Updater mutation-point review found one distinct staged-copy path not covered by the prior `check_temp_dir_and_run()` recovery test: `_handoff_to_new_updater()` copies the extracted updater with `shutil.copy2`. Added `test_handoff_recovers_after_process_exit_during_updater_copy`; it terminates only its controlled Python child after writing a partial file under pytest's temporary install tree, then verifies a fresh handoff overwrites the fragment and launches the complete staged file. No updater production code changed.
- `Updater.terminate_processes()` previously attempted substring matching on every `proc.info["name"]`; psutil 7.1.0 uses `None` by default when prefetching an attribute raises `AccessDenied` or `ZombieProcess` (version is pinned in `uv.lock`). A nameless process could therefore raise `TypeError` before the intended target process was reached. Added a mocked-process regression, observed it fail with `TypeError` before the fix, then changed the filter to skip non-string names without changing matching or termination behavior. The test does not enumerate or terminate real processes.
- Full-update deletion review found two related failure cases. A `PermissionError` after partial removal of the old `assets/images` tree was logged and ignored, allowing copy, payload cleanup, and apparent success. Separately, Python 3.12 `shutil.rmtree()` can propagate `FileNotFoundError` from a child operation; the updater treated every such exception as proof that the root was absent. A regression reproduced the latter as a successful update with stale old resources still present. `cover_folder()` now treats `FileNotFoundError` as benign only if `os.path.lexists(delete_folder_path)` is false; if the root remains, it raises a contextual `RuntimeError`. Other deletion errors also abort. The tests verify failed updates retain the partial old tree and payload, write no completion marker, do not launch the application, and preserve an outside sentinel. They also verify a missing old-resource root is benign and a fresh updater instance can later reuse retained payload, remove the remaining old file, install the new image, and clean the payload and archive.
- Initial EGO gift selection previously had an inner slash-gift scroll loop that could keep dragging forever when the expected blunt-gift marker never appeared, bypassing the outer 30-attempt recognition limit. It now allows at most 12 drags and raises `cannotOperateGameError` if the scroll target remains unresolved. Regressions verify failure at exhaustion without selecting a card and successful continuation when the target appears on attempt 12. These tests verify control flow with mocks; they do not verify visual detection or scroll distance on a live layout.
